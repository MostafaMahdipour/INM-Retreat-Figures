# INM Retreat Figures

This repository contains figures prepared for the INM Retreat presentation based on our published study:

> Mahdipour, M., Maleki Balajoo, S., Raimondo, F. et al.  
> Exposome-wide patterns predict brain health in aging.  
> *Nature Communications* **17**, 3409 (2026).  
> https://doi.org/10.1038/s41467-026-71271-9
